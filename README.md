# SimpleCalculator

A simple C++ calculator developed as part of our Git tutorial.

## Features
- Addition
- Subtraction
- Multiplication
- Division with a check for division by zero

## Compilation
Compile the program using:
```bash
g++ Calculator.cpp -o Calculator.exe
```

## Execution
Run the generated executable from the terminal:
```powershell
.\Calculator.exe
```

## Git Tutorial
This project demonstrates Git commits, branching, merging,
merge conflict resolution, and synchronization with GitHub.
